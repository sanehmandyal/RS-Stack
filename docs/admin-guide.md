# Admin guide

Sign in at `/admin/login`. Menu items depend on your role.

- **Dashboard**: real counts from the database (leads by status, 30-day trend, sources, published content).
- **Leads**: search/filter, open a lead to change status, assign (Admin+), set follow-up, add internal notes, mark spam, archive, export CSV (Admin+).
- **Services / Projects / Blog / Testimonials / FAQs**: create, edit, delete, publish. Mark sample projects as Demonstration. Testimonials need “verified” and a consent reference before they can be published. Blog posts support drafts and future publish dates (scheduling).
- **Media**: upload images and set alt text; copy the URL into content.
- **SEO metadata / Redirects**: per-path titles, descriptions, canonical, noindex, sitemap inclusion; validated redirects.
- **Local SEO clients, Profile tasks, Directory listings**: manual record-keeping. Record client authorisation; never store passwords.
- **Ad campaigns, Domains & hosting**: manual records, not live platform data.
- **Settings**: contact details, WhatsApp number, social links, home page copy.
- **Integrations**: honest status of configured/manual integrations. **Users** and **Audit log**: Super Admin only.
- **Account**: change your password (signs you out everywhere).
